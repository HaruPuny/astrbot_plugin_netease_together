# astrbot_plugin_netease_together

让 AstrBot 接入网易云**官方双人「一起听」**：读出正在听的歌和完整歌词，并在你明确授权时暂停、继续、切歌、插播、退出。

> **本插件不能单独运行。** 它只是 AstrBot 与 [Cove Resonance](https://github.com/yanceydaisy/cove-resonance) 桥接服务之间的适配层；音乐能力全部由 Cove 提供，本插件只负责在 QQ 里把你的意图安全地转成一次桥接调用。

---

## 特性

- 只有主人本人的 QQ 私聊可用；群聊、其他私聊、定时任务一律拒绝
- 只读视图：状态、当前歌曲、完整歌词、搜索歌曲、歌单列表、歌单曲目
- 播放控制：暂停、继续、下一首、切到队列内歌曲、插到下一首、退出
- 写操作要求**主人本轮直接发送的纯文字**，引用、转发、语音转写、模型自行计划都不能授权
- 控制不会“发出去就算成功”，会等待网易云实时回执确认
- 歌词、歌名等外部内容一律标记为不可信资料，其中的“指令”不构成授权
- 不保存 Cookie、令牌、邀请链接或聊天内容；控制审计只记动作与状态

## 前置要求

本插件依赖一套你自己部署的桥接服务，缺一不可：

1. **Cove Resonance 服务**（需包含定制工具 `netease_together_join` / `netease_together_lyrics` / `netease_together_status`，并启用强制 Bearer 验证；纯上游版本不满足要求）
2. **一个网易云账号 Cookie**（建议使用小号，仅由 Cove 以文件形式读取）
3. **一份随机桥接令牌**，AstrBot 与 Cove 两侧保持一致
4. **你的网易云数字 UID**（不是 QQ 号），必须与 Cove 的 `NETEASE_INVITER_UID` 一致

Cove 需在 AstrBot 可访问的内网中监听 8787，**不要映射到公网**。

## 安装

1. 把本目录打包成标准 AstrBot 插件 ZIP 并上传安装，或直接放入 `data/plugins/`
2. 在 AstrBot 插件配置页填写：
   - `platform_id`：你的 QQ 平台 ID（留空则跳过该校验）
   - `owner_umo`：形如 `<platform_id>:FriendMessage:<主人QQ号>`；也可留空并依赖 `master_aware` 的主人 QQ 列表
   - `owner_netease_uid`：你的网易云数字 UID
   - `bridge_url`：内网地址，默认 `http://cove:8787/mcp/music`，路径固定且仅接受私有地址
   - `bridge_token_file`：容器内令牌文件的绝对路径
3. 把同一份令牌写入 `bridge_token_file` 指向的文件（权限 600）
4. 填好之后再打开 `enabled`

`requirements.txt` 声明的 `mcp` 与 `httpx` 通常已由 AstrBot 运行时提供，无需为插件升级框架依赖。

## 使用

先在 QQ 私聊发送 `/一起听` 查看帮助。以下指令不调用语言模型：

```text
/一起听 状态                     桥接与房间状态
/一起听 当前                     当前播放的歌曲
/一起听 歌词                     完整歌词（受 max_lyrics_chars 限制）
/一起听 搜索 歌名或歌手
/一起听 歌单                     我的歌单
/一起听 歌单 <歌单ID>             某歌单曲目
/一起听 加入 <双人邀请链接>        进入房间
/一起听 暂停
/一起听 继续
/一起听 下一首
/一起听 切歌 <歌曲ID>             仅限当前队列内已有的歌
/一起听 下首 <歌曲ID>             插入到下一首
/一起听 退出
```

也可以直接把网易云官方双人邀请整条发过来（形如“我的耳机分你一半，和我一起听歌吧～快点开看看 <链接>”），或使用自然语言如「现在放的是什么歌」「暂停播放」「退出一起听」。

**授权规则：** 邀请必须是主人本轮直接发送的纯文字链接，邀请者 UID 需与配置一致；只接受 `music.163.com` / `st.music.163.com` 的官方双人邀请，不跟随短链接，不支持新版 `multishare/inviterUid` 多人邀请。请求超过 10 分钟视为过期。

## 已知限制

- **Cove 重启后不会自动回到房间**，需要主人重新发送一次有效邀请
- 未绑定房间不等于已从远端房间退出；缓存状态不能证明一次超时操作完全没有发生
- 超时或中断的控制记录为 `uncertain`，不会自动重试，请先查状态再决定是否重新发起
- 不监听、不主动回复网易云聊天室；只在主人发话时回应
- 不提供收藏、点赞、歌单增删、账号管理等写操作
- 知道歌名和歌词不等于模型听到了旋律与音色

## 安全说明

- 账号 Cookie 与桥接令牌不进入插件配置界面、模型上下文或日志
- 桥接地址必须是私有地址，路径固定为 `/mcp/music`
- 身份校验基于真实 OneBot 消息元数据（`post_type`、`message_type`、`user_id`、`message_id`、`self_id` 与消息时间），不采信模型传入的身份或 `confirm` 参数
